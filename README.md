## 🌟 Overview

**CompScout** is a free, open-source UI component library designed for modern web applications. Unlike traditional component libraries where you install a heavy npm package, CompScout gives you the **freedom to copy and paste** the raw component code directly into your project. You own the code!

## 🚀 Features

- **Copy & Paste Ready:** Grab the exact code you need without bloat.
- **Dual Language Support:** View and copy components in both **TypeScript (TSX)** and **JavaScript (JSX)** dynamically.
- **Dark Mode Native:** Every component is meticulously designed to look stunning in both Light and Dark themes.
- **Interactive Feedback:** Features micro-interactions and built-in UI sounds using the Web Audio API.
- **Fully Responsive:** Tested across all screen sizes with seamless mobile drawer navigation.
- **Modern Stack:** Built on top of `Next.js 14`, `Tailwind CSS v4`, `Motion`, and `Lucide React`.

## 🛠️ Tech Stack

- **Framework:** [Next.js (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Motion (Framer Motion)](https://motion.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 📦 How to Use

1. Browse the components at [compscout.dev](https://compscout.dev).
2. Click on any component from the sidebar to preview it.
3. Switch to the **Code** tab.
4. Toggle between **TypeScript** and **JavaScript** depending on your project setup.
5. Click **Copy Code** and paste it directly into your codebase!

## 💻 Local Development

Want to run CompScout locally or contribute to the library? Follow these steps:

```bash
# 1. Clone the repository
git clone https://github.com/kailash9711/compscout.dev.git

# 2. Navigate to the project directory
cd compscout.dev

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
Your local environment will be running at `http://localhost:3000`.
